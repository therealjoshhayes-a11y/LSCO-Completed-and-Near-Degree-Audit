# Raw Catalog Sources

Place public catalog source files here by catalog year.

Expected layout:

```text
2022-2023/
2023-2024/
2024-2025/
2025-2026/
```

Each year folder may contain the source PDF and DOCX named in `config/catalogs.csv`.

Do not place Banner, Argos, DegreeWorks, or student-level data in this folder.
